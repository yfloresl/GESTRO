# Roadmap (semanas estimadas con Claude Code; supuesto de trabajo)

Sistema: F0 fundaciones (0-3) · F1 núcleo, menú, salón, QR (2-9) · F2 recetas, plan, inventario, KDS (8-14) · F3 caja, recibos, contabilidad (12-18) · F4 reservas, eventos, personal, promociones (15-20) · F5 inteligencia (18-23) · F6 piloto (22-26)

Fiscal SIN: S0 documentación y diseño (0-3) · S1 CUIS, CUFD, catálogos en piloto (3-8) · S2 emisión, XML, firma (7-13) · S3 contingencia, anulación, paquetes (12-17) · S4 pruebas de autorización ante el SIN (15-23) · S5 producción, API y SDK (22-26)

La autorización ante el SIN depende de sus plazos (trámite de 90 días, prorrogable 60).
